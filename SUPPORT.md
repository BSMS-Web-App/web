# BSMS Web — Support

Need help with BSMS Web? You can ask the community on Discord or open a GitHub issue.

## Getting Support

There are two ways to get support for BSMS Web.

### 1. Ask the Community on Discord

Join the [BSMS Web Discord server](https://discord.gg/ySwEjEqjf) to ask community members for help, troubleshoot problems, ask questions about features, and discuss BSMS Web.

Choose the appropriate channel for your request:

- **`chat`** — Ask general questions and get help from other community members.
- **`bug-reports`** — Discuss problems and unexpected behavior.
- **`feature-requests`** — Suggest new features and improvements.

Please provide enough detail for others to understand your question, and remain respectful of other community members.

**Join Discord:** https://discord.gg/ySwEjEqjf

### 2. Open a GitHub Issue

If you prefer, you can request support by opening an issue in the BSMS Web GitHub repository.

**[Open a GitHub Issue](https://github.com/JellyfishJelly13/BSMS-Web/issues/new/choose)**

GitHub Issues can be used to ask for assistance, report problems, and explain unexpected behavior. If an appropriate issue template is available, select the one that best matches your request.

When opening a support issue, include:

- **Summary:** What do you need help with?
- **Affected feature:** Which page or feature is involved?
- **Steps to reproduce:** What were you doing when the problem occurred?
- **Expected behavior:** What did you expect to happen?
- **Actual behavior:** What happened instead?
- **Additional details:** Relevant error messages, screenshots, browser information, or device details.

Check existing issues before opening a new one to avoid duplicates.

## Reporting Bugs

If you believe you have found a bug, you can report it through GitHub Issues.

Please provide clear reproduction steps and explain what went wrong. Screenshots and relevant error messages can help maintainers investigate the problem.

For issues affecting a contributor's development environment, include the affected branch and deployment URL when relevant.

## Requesting Features

Have an idea for a new feature or improvement? You can discuss it with the community on Discord or submit a feature request through GitHub Issues.

Explain the problem your idea would solve, how you would expect it to work, and who might benefit from it.

Feature requests are suggestions and are not guaranteed to be implemented.

## Deployment and Contributor Support

Contributors who need help with development branches, pull requests, or Vercel deployments can ask the community on Discord or open a GitHub issue.

BSMS Web uses the following branch and deployment conventions:

| Environment             | Branch        | Deployment                                         |
| ----------------------- | ------------- | -------------------------------------------------- |
| Production              | `main`        | [bsms-web.vercel.app](https://bsms-web.vercel.app) |
| Contributor development | `dev[number]` | `bsms-web-dev[number].vercel.app`                  |

Each contributor has their own assigned development branch and corresponding deployment. Contributors should test their changes in their assigned environment before submitting a pull request.

Only authorized maintainers may merge changes into `main`, subject to the repository's protection rules and required checks.

## Security Vulnerabilities

**Do not report security vulnerabilities through public GitHub issues or Discord channels.**

Follow the private reporting instructions in [`SECURITY.md`](SECURITY.md).

Never share passwords, access tokens, private keys, or other sensitive information in public support requests.

## Support Guidelines

- Be respectful and constructive when asking for or providing help.
- Search existing GitHub issues before creating a duplicate.
- Provide enough information for others to understand the problem.
- Do not post sensitive information, credentials, or private user data.
- Understand that support is provided on a best-effort basis; response times are not guaranteed.
