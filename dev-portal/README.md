# BSMS Web Developer Portal prototype

A UI-only prototype of the planned internal developer portal.

## Files
- index.html: overview dashboard, branch cards, usage panels, activity and directory preview
- portal.css: responsive dark glass UI
- portal.js: demo interactions only

## Important
This is a visual prototype, not an operational deployment platform. It does not authenticate users, read branch assignments, enforce limits, invoke Vercel, or run deployments. All example branches, commits and usage are placeholder data. Any production implementation must add a backend and enforce every permission and limit server-side.
