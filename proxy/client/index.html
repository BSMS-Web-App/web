About BSMS Web Proxy

This is an early interface preview. The proxy gateway has not been implemented, so entering an address will not visit that website.

When operational, destination websites will generally see the proxy server's outbound IP. The proxy service itself can still receive your IP address. This is not a VPN or an anonymity guarantee.
