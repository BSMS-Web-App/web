ABOUT THE BROWSER

How it works

BSMS Web Browser is a lightweight web reader built into BSMS Web. It is not a full Safari or Chrome browser engine.

  1. Browser interface: The browser controls and interface are served by BSMS Web.
  2. Page requests: When you open a website, its page is requested through the BSMS Web Reader service on Cloudflare.
  3. Account check: The reader checks your BSMS account session with the BSMS Web API before serving a page. The API verifies the session; it does not fetch the website for the reader.
  4. Page adaptation: Supported page links and resources are adjusted to load through the reader service. Some browser features and website behaviors are not fully supported.

Still in beta: Some pages will not load or function properly. Compatibility is being improved over time.
